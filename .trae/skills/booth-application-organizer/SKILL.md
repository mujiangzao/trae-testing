# 摊位申请表整理流程

## 触发条件
当用户请你「整理摊位申请表」时，执行以下完整流程。

## 文件位置
所有操作均在项目根目录的「摊位申请」文件夹内完成：

- 申请表：`摊位申请/` 内所有 Word 文件（`.doc` / `.docx`）
- 统计表：`摊位申请/摊位申请表统计.xlsx`
- 处理日志：`摊位申请/处理日志.md`

## 前置步骤

1. 读取 `摊位申请/处理日志.md`，取得已处理文件名集合（日志中以 `- ` 开头的每一行对应一个已处理文件名）。
2. 列出「摊位申请」文件夹内所有 `.doc` / `.docx` 文件，文件名未出现在日志中的即为本次待处理文件。
3. 若没有待处理文件，告知用户「没有新的摊位申请表需要处理」，流程结束。
4. 若「处理日志.md」或「摊位申请表统计.xlsx」不存在或无法读取，暂停流程并提示用户。

## 步骤一：文件重新命名

将每个待处理文件重命名为 `摊位申请表-xxx.docx`（原扩展名为 `.doc` 的保留 `.doc`）。

`xxx` 为班级缩写，规则：**年级数字 + 班号数字**（1 年 1 班 → `101`，2 年 2 班 → `202`，以此类推）。

班级缩写来源（按优先级）：

1. 优先从原文件名判断班级，如「三年二班申请表.docx」→ `302`。
2. 文件名无法判断时，读取 Word 文件表格中的「申请班级」（或「班级」）字段，如「一年级（1）班」→ `101`。
3. 中文数字对照：一→1、二→2、三→3、四→4、五→5、六→6，年级与班号同理。

补充规则：

- 仍无法确定班级的文件：暂停流程，向用户报告文件名及原因。
- 若目标文件名已存在（撞名）：暂停流程并提示用户，切勿覆盖。

## 步骤二：资料登记（写入 Excel）

从每个已重命名的 Word 文件表格中读取字段，追加写入 `摊位申请/摊位申请表统计.xlsx` 的最后一行（紧跟现有数据之后，不覆盖任何既有行）。

统计表已知结构：第 1 行为合并标题行，第 2 行为表头，数据从第 3 行开始。列依次为：

> 编号 | 申请日期 | 申请班级 | 摊位名称 | 摊位类型 | 负责教师 | 联系电话 | 联系邮箱 | 摊位简介 | 所需桌椅 | 志愿者人数 | 用电需求 | 用电设备（名称与功率） | 备注 | 审核意见 | 来源文件

执行时先核对第 2 行表头，若实际列顺序或列名不同，以实际表头为准进行映射。

字段取值规则：

- **编号**：在现有所有编号的最大值基础上递增，格式 `CB-2026-XXX`（如已有最大编号 CB-2026-015，则新行从 CB-2026-016 开始）。
- **申请日期**：取处理当日日期，格式与现有行一致（如「2026年9月15日」）。
- **申请班级 / 摊位名称 / 负责教师 / 联系电话 / 联系邮箱 / 摊位简介 / 所需桌椅 / 志愿者人数 / 备注**：取 Word 表格对应字段原文。
- **摊位类型**：取表单中打勾「☑」的选项文字（去掉勾选符号，如「游戏互动」）；若勾选「其他」，取其后填写的补充内容。
- **用电需求**：「☑是」记「是」，「☑否」记「否」。
- **用电设备（名称与功率）**：取「设备名称与功率：」之后的文字。
- **审核意见**：申请方提交的表格此栏为空，留空即可。
- **来源文件**：重命名后的新文件名（如「摊位申请表-404.docx」）。

全部写入完成后，对数据行按**班级缩写**递增排序（101, 102, 103, …, 201, 202, …）：

- 班级缩写 = 年级 × 100 + 班号，由「申请班级」列换算（「一年级（1）班」→ 101）；「申请班级」缺失时可从「来源文件」文件名中的编号换算。
- 若表中实际存在「班级缩写」列，则直接按该列排序。
- 标题行与表头行保持不动，仅重排数据行；整行移动，编号随行移动、不重新生成。

## 步骤三：更新处理日志

将本次**成功处理**的所有 Word 文件名（重命名后的新名称）追加到 `摊位申请/处理日志.md` 的末尾，每条记录占一行，格式与现有记录一致：

```markdown
- 摊位申请表-404.docx
```

如需按时间留痕，可在新增记录前先追加一行日期小节标题（如 `## 2026年9月18日`），再逐行追加文件名。

## 注意事项

- 任何 Word 文件无法读取、或关键字段（申请班级、摊位名称、负责教师、联系电话等）缺失或无法解析时：**暂停整个流程**，向用户报告具体文件与问题，待用户确认后再继续。
- 一次处理多个文件时，按班级缩写从小到大依次处理。
- 重命名、写入 Excel、更新日志过程中如遇目标文件名冲突、Excel 被占用等情况，同样暂停并提示用户。
- 流程结束后向用户简要汇报：本次处理的文件列表、Excel 新增行数、排序结果、日志更新情况。

## 工具提示

- 读取 Word 表格：`python-docx`（`pip install python-docx`）。
- `.doc` 旧格式先转换为 `.docx` 再处理：`libreoffice --headless --convert-to docx <file> --outdir <dir>`（重命名仍保留 `.doc` 扩展名时，以转换出的 `.docx` 内容为准）。
- 读写 Excel：`openpyxl`（`pip install openpyxl`）。追加时用 `ws.max_row` 定位最后一行；排序时保留标题行与表头行，仅重排数据行，并注意避开合并单元格区域。
